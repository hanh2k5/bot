# 🚀 LeadHunter Bot - Thợ Săn Số Điện Thoại Tốc Độ Cao (Bản Miễn Phí 100%)

Bot tự động cào số điện thoại khách hàng tiềm năng từ Google Maps. Được thiết kế đặc biệt cho dân Sales với tiêu chí: **Nhanh - Gọn - Sạch - Dễ Dùng**.

---

## 🛠 HƯỚNG DẪN CÀI ĐẶT TRÊN MÁY MỚI (CHỈ MẤT 1 PHÚT - 1 CLICK SETUP)

### 📌 BƯỚC 1: Cài đặt Python (Nếu máy chưa có Python)

* **Trên Windows:** Tải Python 3.12 từ link: 👉 **[Download Python 3.12](https://www.python.org/ftp/python/3.12.8/python-3.12.8-amd64.exe)**
  *(Lưu ý: Mở file cài đặt nhớ tích vào ô ☑️ **Add python.exe to PATH** ở góc dưới)*

* **Trên macOS:** Mở Terminal và dán lệnh: `brew install python` (hoặc tải installer từ python.org).

* **Trên Linux (Ubuntu/Debian):** Mở Terminal và dán lệnh: `sudo apt update && sudo apt install -y python3 python3-pip`

---

### 📌 BƯỚC 2: Cài Đặt 1-Click (Chạy 1 lần duy nhất khi mới tải code)

* **Trên Windows:** Nhấp đôi chuột vào file **`setup.bat`** nằm trong thư mục code.
* **Trên Linux / macOS / WSL:** Mở Terminal dán lệnh: `bash setup.sh`

*(Hệ thống sẽ tự động tải các thư viện và trình duyệt Chromium Playwright đầy đủ trong 30 giây).*

---

## 🚀 HƯỚNG DẪN SỬ DỤNG (CHỈ CẦN GÕ 1 TỪ: `run`)

Mở Terminal / CMD / PowerShell lên và gõ:

```bash
run
```

Giao diện Web UI mượt mà sẽ tự động hiển thị để bạn nhập Từ Khóa và bấm **▶ Bắt Đầu**!

## 🌟 Các Tính Năng Nổi Bật

- **Miễn Phí 100%:** Không cần mã kích hoạt, không giới hạn tính năng.
- **Sàng Lọc Thông Minh:** Mặc định tự động lọc bỏ Số bàn / Tổng đài (028, 024, 1900, 1800...).
- **Tùy Chọn Mở Rộng:** Dễ dàng tích chọn `+ Viettel` hoặc `+ Có Web` trực tiếp trên Giao Diện.
- **Khử Trùng Lặp 2 Lớp:** Tự động phát hiện và bỏ qua các SĐT đã từng cào trước đây.
- **Đa Nền Tảng:** Chạy mượt mượt trên Windows, macOS và Linux.
